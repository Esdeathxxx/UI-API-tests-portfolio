# Java AQA Portfolio (Java 26)

Проект по автоматизации тестирования UI и API с использованием современного стека технологий на Java. Предназначен для демонстрации навыков проектирования архитектуры автотестов.

## Стек технологий
* **Язык программирования:** Java 26
* **UI Автоматизация:** Selenide
* **API Автоматизация:** RestAssured, Jackson Databind (POJO моделирование)
* **Тест-фреймворк:** JUnit 5
* **Сборщик проектов:** Maven
* **Отчетность:** Allure Report

## Покрытый функционал (Тест-кейсы)

### UI Тестирование (Интернет-магазин Swag Labs)
* **E2E Сквозной заказ:** Авторизация под валидным пользователем, добавление нескольких товаров в корзину, проверка счетчика, заполнение данных доставки, ассерт стоимости всех товаров в корзине и успешное завершение заказа.
* **Негативная авторизация:** Проверка блокировки пользователя `locked_out_user` и валидация текста системной ошибки.

### API Тестирование (REST API ReqRes)
* **POST /api/users:** Создание нового пользователя с использованием Jackson POJO-моделей (сериализация/десериализация) и проверка возвращаемых сервером данных.
* **GET /api/users?page=2:** Получение списка пользователей, проверка статус-кода 200, структуры JSON-ответа и валидация доменных имен почтовых ящиков через Hamcrest Matchers.

## Архитектурные паттерны и подходы
* **Page Object Model (POM):** Полное разделение логики веб-страниц и логики самих тестов.
* **Умные ожидания:** Использование встроенных механизмов Selenide вместо нестабильных жестких пауз (`Thread.sleep()`), что полностью исключает мигание тестов.

## Локальный запуск проекта

1. Склонируйте репозиторий.
2. Запустите тесты через встроенную панель Maven или через терминал:
   ```
   .\mvnw clean test
   ```
3. Для генерации и открытия интерактивного отчета Allure выполните:
